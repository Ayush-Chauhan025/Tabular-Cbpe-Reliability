# Checked-in experiment outputs

`column_outage_v2_calibration/` contains the recorded conditions (`column_outage_runs.csv.gz`), model/fold summaries, run metadata, and Brier score and equal-width ECE results. The raw table can be used to regenerate the summaries and figures with the scripts in `src/`.

The run metadata records software versions and the number of evaluated outage conditions. The study protocol and limitations are documented in `docs/column_outage_protocol.md`.
